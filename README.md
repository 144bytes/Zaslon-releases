# Zaslon

Защита Telegram-каналов от накрутки ботов. Программа для Windows.

## Установка

1. Скачайте `Zaslon.exe` из последнего [релиза](../../releases/latest) и запустите, установка не нужна.
2. На вкладке «Боты» добавьте токены своих ботов из [@BotFather](https://t.me/BotFather).
3. Назначьте ботов администраторами каналов с правом «Блокировка пользователей».
4. Добавьте каналы на вкладке «Каналы».

Обновления устанавливаются из программы: «Настройки → Общие → Проверить обновления».
